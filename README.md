**Applied Mathematician · Data Scientist · Research Lead · Adjunct Professor**

This repository is the canonical public version of my professional CV. It brings together academic research, industrial R&D, teaching, scientific software, public projects, publications, funding, leadership and technical work in one place.

The private `resume` repository is used for tailored job applications. This public repository is deliberately broader and more stable.

## Industrial research at Utopi

The public CV describes my Utopi work at a level that establishes the mathematical and technical contribution without publishing client data, internal thresholds, proprietary calibration choices or implementation details.

| Project area | Public description |
| --- | --- |
| **Energy benchmarking & technical efficiency** | Weather-normalised benchmarking combining change-point modelling, stochastic frontier analysis, efficiency estimation, quality controls and portfolio reporting. |
| **Mould-risk analytics** | Hourly mould-risk modelling based on published Ojanen/VTT methodology using indoor environmental telemetry. |
| **Legionella proxy risk** | Risk prioritisation combining occupancy/stagnation evidence with thermal behaviour to support targeted operational checks. |
| **Heat-loss estimation** | Inverse cooling-event models that estimate relative heat-loss behaviour from passive temperature decay. |
| **Anomalous heating / rogue heaters** | Statistical detection of indoor-temperature behaviour inconsistent with expected outdoor conditions, prior state and occupancy evidence. |
| **Unoccupied-heating analytics** | Portfolio analysis identifying persistent heating where occupancy evidence is low. |
| **Utopi Index / BEPS** | Multi-signal building-performance scoring framework productionised as a deployable analytical service with validation and model-QA workflows. |

## Academic profile

My research spans celestial mechanics and dynamical systems, spacecraft attitude dynamics, numerical analysis, stochastic modelling, optimisation, scientific computing, quantitative finance, energy analytics and applied AI. I have more than twenty years of university teaching, research and academic leadership experience across the UK, Middle East and Southeast Asia.
